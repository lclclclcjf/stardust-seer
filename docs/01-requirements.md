# 01 - 需求规格说明书

## 项目名称

🌸 樱花塔罗牌 (Sakura Tarot)

## 产品定位

一款运行在浏览器中的塔罗牌占卜网页应用（PWA），樱花粉色为主色调，面向塔罗爱好者和日常占卜需求。

## 目标用户

- 对塔罗牌感兴趣的普通用户
- 不需要专业知识，直觉操作即可完成占卜
- 在 Windows PC 和 iPhone 上使用

## 功能清单

### P0（核心功能，必须实现）

| 编号 | 功能 | 描述 |
|------|------|------|
| F01 | 78 张塔罗牌数据 | 大阿尔卡纳 22 张 + 小阿尔卡纳 56 张，含牌名、关键词、正逆位解读 |
| F02 | 随机抽牌 | Fisher-Yates 洗牌算法，随机抽取，正逆位各 50% 概率 |
| F03 | 三种牌阵 | 单张牌、三张牌（过去·现在·未来）、凯尔特十字（10 张） |
| F04 | 牌面展示 | 四种视觉风格的卡片正面 + 对应牌背 |
| F05 | 牌义解读 | 中英双语展示关键词、正位含义、逆位含义 |
| F06 | 问题输入 | 抽牌前可输入问题（可选填） |

### P1（重要功能）

| 编号 | 功能 | 描述 |
|------|------|------|
| F07 | 四种牌面风格 | 日式樱花 / 梦幻治愈 / 经典重构 / AI 自由发挥 |
| F08 | 历史记录 | 本地保存占卜历史，可查看和删除 |
| F09 | 洗牌翻牌动画 | CSS 动画，增强仪式感 |
| F10 | 音效（可选） | 默认关闭，设置中可开启 |

### P2（后续升级）

| 编号 | 功能 | 描述 |
|------|------|------|
| F11 | AI 生成牌面 | 接入 AI 图像生成 API，为每张牌生成独特牌面 |
| F12 | AI 深度解读 | 接入 AI 文本生成，结合用户问题进行个性化解读 |
| F13 | 语言切换 | 中/英/日多语言支持 |

## 非功能需求

- **响应式设计**：适配 PC 和手机屏幕
- **PWA**：可添加到 iPhone 主屏幕
- **离线可用**：数据纯前端，无网络依赖
- **性能**：首次加载 < 3 秒
- **隐私**：所有数据存储在浏览器本地，不上传服务器

## 用户故事

1. 用户打开网页 → 看到樱花粉色界面 → 选择牌面风格 → 选择牌阵 → 输入问题 → 点击开始占卜
2. 系统展示洗牌动画 → 用户点击选牌 → 牌面翻转 → 显示解读内容
3. 用户可查看历史记录 → 回顾之前的占卜结果

## 平台约束

- Windows：Chrome / Edge 浏览器
- iPhone：Safari 浏览器，iOS 15+
- 不开发原生 App
